## Numerical protocols and evaluation units

Association cells retain their recorded integer sampling device: the original
CPU integer plans and probability rounding for retained cells, and CUDA plans
for subsequently updated cells. Ranks, correlations, reductions and quantiles
execute on CUDA. Dose bootstrap uses the original NumPy PCG64 integer plans,
including finite-update group boundaries, with numerical statistics on CUDA.
Figure 4's primary 2,000-draw intervals and its separate 5,000-draw sensitivity
are distinct protocols.

The saved-model evaluation first verifies 4,819 frozen queries and applies the
reviewed two-UTS/nine-elongation exclusion list to obtain 4,808 publication
queries. Predictions, labels and model parameters remain fixed. Query and
source-key counts are evaluation units, rather than independent specimen or
state counts. UTS queries q66/q67 are retained with unresolved same-state alias
independence. The supplied qualification record includes exact query/member
identities and target-specific coverage.

Input-resolution references use a finite recorded candidate set, a single
choice per source, the saved input representation and equal choice probability
within input-identical groups under the stated exchangeability assumption.
The opportunity and input-block references use observed labels retrospectively.
Effects of additional descriptors on learned prediction require evaluation on
the predictor's stated cohort and information budget.

## Admitted material-analysis inputs

The dataset supplies scoped numerical inputs under `data/`. These are
figure-specific analysis records drawn from the curated database.

- `TITMC_FIG08_strength_ductility_states.csv`: the admitted RT and 500–<800 °C
  pairs. `el` is recorded elongation in percent, `uts` is strength in MPa;
  `observation_id` and `paired_observation_id` retain the two measurement
  identities. `paper_family_id`, `doi` and both source locators bind the pair.
  Primary interval references and variance-decomposition references are separate.
- `TITMC_FIG07_pareto_audit_*`: admitted and retained-excluded frontier pairs,
  original year masks, source support and numerical references. `year_eligible`
  retains the original source-year rule; an eligible state does not establish an
  independent specimen. Values, definitions and exclusions are not harmonized anew.
- `TITMC_FIG04_temporal_frontier_states.csv`: only the original main-RT-admitted
  observations. `value`, `year`, `temperature_c`, `endpoint_id`, units and DOI
  remain attached. `source_order_code` is a DERIVED encoding of original
  first-seen source order from saved row accounting; it preserves source-draw
  identities and carries no measured material property. No full raw corpus is
  included. The reference table also retains its separately labeled screening
  lane, which is outside the admitted-main replay.
- `TITMC_FIG16_microstructure_source_data.csv`: the six original same-row
  descriptor/property selections. Named size fields are in micrometers; phase
  fractions retain their recorded percent definitions. The replay reconstructs
  `x` from `descriptor_field` and `y` from the original `value` without deriving
  a size from a morphology tag or a phase fraction from its complement.
- `TITMC_REF11_admitted_units.csv`: each row
  identifies a feature/endpoint cell and an original source/state analysis unit;
  `x`, `y` and any `control_N` fields are the original collapsed numerical
  inputs. `value_origin` explicitly marks DERIVED original analysis-unit medians.
  DOI lists and `source_record_ids` retain contributing evidence. Feature and
  endpoint indices preserve the original per-cell bootstrap seed rule.
  The protocol metadata identifies each cell's recorded sampling backend from
  the original execution record; no backend is chosen by matching an
  observed effect or interval.
- `material_dose_series.csv.gz` and `material_dose_series_points.csv.gz`: all
  supplied admitted condition series and dose-level points. Numeric dose bases,
  endpoint units, matrix/process/test context and source locators remain distinct.
  `material_dose_source_effects.csv.gz` and `material_dose_summary_effects.csv`
  are references for the original source aggregation and bootstrap. The replay
  reconstructs each series' OLS/interval changes from its points before source
  summaries; observations are not re-admitted from the complete curated table.
  Per-cell PCG64 states are reconstructed from the original full-run and finite
  update source membership, preserving the original 6/6/26 affected-cell
  boundaries rather than drawing all current groups from a new common stream.
- `addition_maps_*.csv`: the current designed-series subset, fingerprints,
  source-weighted medians/intervals, reinforcement-content bins and source-level
  contrasts used by Figures 11–12. Their numerical calculation is
  supplied as `tools/reproduce_addition_maps.py`.

## Scientific extraction protocol

`extraction_tasks.jsonl` retains the actual scientific instructions, output
schema, query selectors and evaluation scope. `original_source` records the
identity and completeness of documents supplied in the original experiment;
the documents themselves are not distributed. DOI and source hashes identify
the originals for lawful acquisition. These tasks were also used during method development.

`extraction_reference.jsonl` preserves declared values, units, state/query
identities, eligibility and locators, including ineligible references.
`extraction_predictions.jsonl` preserves parsed saved outputs, failures, actual
model/reasoning settings and declared budgets. API calls, development
conversations, full publisher XML, credentials and account usage are excluded.
The generic scalar/record scorer is supplied separately from the source-scoped
query projections. A complete source-scoped re-score additionally requires the
original protocol adapter; these projections document the completed runs.

This release contains the recorded candidates, saved predictions, feature matrices,
and source-level results used in the retrospective selection analysis. The original
relative paths are retained so each table can be matched to its scientific source.

## Cohort

The frozen prediction pool contains 1,111 paired strength–elongation candidates from
336 source groups. The endpoint review listed in SOURCE_QUALIFICATION.json excludes 41
pairs. Of the 1,070 retained pairs, 913 belong to 168 source groups with at least two
candidates. These 168 groups form the comparison cohort. Singleton sources are not
comparisons between alternatives.

The exclusion list changes the evaluation cohort. It does not retrain or retrospectively
requalify the archived prediction models. A source exclusion is not a statement that
the source paper is scientifically invalid.

## Identifiers and quantities

| Field | Meaning |
| --- | --- |
| observation_id_uts | Stable identifier for the recorded tensile-strength observation. |
| observation_id_el | Stable identifier for the paired elongation observation. |
| paper_family_id | Source grouping used for splitting and evaluation. |
| doi | DOI of the source publication, where available. |
| feature_row_id | Identifier in the frozen feature table. |
| material_id | Recorded material-state identifier. |
| fold / outer_fold | Saved outer source split. Candidates from a source share a fold. |
| uts_mpa | Recorded ultimate tensile strength, in MPa. |
| elong_pct | Recorded elongation, in percent. |
| q | Minimum of UTS/1000 MPa and elongation/10 percent. |
| decision_score | Saved property-model selection score. |
| ranking_score | Saved source-aware ranking score; not a probability. |
| primary_cohort | Whether the source has at least two retained candidates after qualification. |
| requested_k / actual_budget | Requested number of selections and the number available. |
| attainment | Whether a selected set contains a recorded candidate with UTS >= 1000 MPa and elongation >= 10 percent. |
| precision | Fraction of selected candidates meeting both thresholds. |
| regret | Best recorded q in the source minus the best selected q. |
| observed_* / *_evaluation_only | Quantities evaluated using recorded outcomes; not inputs available before a choice. |
| *_ci95_low / *_ci95_high | Archived pointwise 95% source-bootstrap interval limits. |

Missing numerical features remain missing. Category markers such as UNKNOWN retain
their recorded meaning; they are not measurements. ANALYSIS_CONFIG.json names the
39 numerical and five categorical features. Composition fields use mass percent
unless the field explicitly specifies volume percent. Temperature is in degrees
Celsius. The strain-rate feature in candidate_inputs.csv is log10 of the positive
rate in inverse seconds, following the frozen preprocessing.

## Files

### Saved prediction pool

paper01/source_data/TITMC_PAPER01_source_heldout_decisions.csv contains the saved
paired outcomes, predictions, source assignments, and selection ranks. A candidate
appears once per evaluated property-model method. Rows marked admitted=False
describe earlier pairing exclusions and are not part of the 1,111-candidate pool.

### Predictive utility

paper01/analysis/predictive_utility/ contains the current source inventory,
source-level fixed-budget evaluations, and their aggregate summaries.
The primary cohort uses min(k, n) selections within each source. The exact-budget
sensitivity includes n >= max(2, k); the remaining-choice sensitivity uses n > k.
Read the cohort column before comparing rows with different denominators.

The inventory retains the complete frozen source index. For sources with zero
retained candidates, the descriptive columns refer to the frozen pool.
The current eligibility fields are n_candidates and primary_cohort.

### Source-aware ranking and representation

paper01/analysis/source_aware_ranking/candidate_inputs.csv contains the frozen
preprocessed input fields for all 1,111 candidates. No property outcome is a feature.

Each encoded_inputs_fold*.npz contains the array X, candidate and source identifiers,
training and test indices, and feature_names (stored under Chinese entry names in the
repository and restored to these names by the restore script). Each matrix encodes the same full
candidate pool using transformations fitted only on that fold's training sources.
Use the held-out fold for each source. Load these archives with allow_pickle=False.

out_of_source_rankings.csv, alpha_selection.csv, and inner_cv_trace.csv describe
the archived source-aware models. They retain their original training population.
The current source_top1_utility.csv and exact_tie_source_utility.csv evaluate only
the qualified comparison cohort.

representation_blocks_label_informed.csv lists the groups of candidates that share
the same input representation within a source. The outcome summaries attached to
these groups are retrospective diagnostics. In particular, a label-informed block
oracle uses the recorded outcomes; it is not an executable prospective selector.

source_representation_resolution.csv retains the complete source index. Use
source_qualified_primary_cohort for the current comparison. The block table and
representation_oracle_by_source.csv contain only the 913-candidate, 168-source-group cohort.

### Sequential selection

paper01/analysis/sequential_design/ contains four policies: the fixed ridge order,
residual-kernel greedy updating, a common first choice followed by uniform selection,
and fully uniform selection. The two uniform policies are exact expectations, not
randomly simulated trajectories.

label_access_log.csv records which outcome becomes available at each step.
outer_training_kernel_scales.csv contains the frozen training-source kernel scales.
The replay uses the original encoded inputs and scales; it does not refit the
property models. Paired gains compare policies within the same sources.

## Reproduction scope

File checksums identify the supplied snapshot. The reproduction program reports
which numerical comparisons it actually completed and writes its results separately.
Archived confidence intervals and historical training diagnostics remain distinguishable
from calculations performed by the public replay.

The release covers the numerical analyses listed in README.md. The complete curated
corpus, the literature extraction system and the figure rendering remain outside it, and
source articles and their figures are not distributed.
